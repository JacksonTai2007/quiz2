【2｜網路：先背 32／128／48】
IPv4 32bits、IPv6 128bits、乙太網 MAC 48bits。
IPv6：::1 回送、:: 未指定、::/0 預設路由；基本標頭固定40bytes。
DNS 域名→IP；DHCP 自動配發網路設定；ARP IPv4→MAC；NAT 私網↔公網位址轉換。
Ping→ICMP；即時音視頻常用 UDP；郵件協議通常 TCP；UDP 不保證重傳/順序。
私有IP：10.*、172.16～172.31.*、192.168.*。80台主機最小常用 /25＝255.255.255.128，可用126台。
傳統 C類第一段192～223；D類224～239（多播）。MAC只可有0～9、A～F，G不合法。
Wi-Fi6＝802.11ax；題內列出的舊加密選項選 WPA2+AES，不要當成現今最強。
傳統 Ethernet 教材：邏輯Bus、雙絞線實體Star；資料連結層第2層（標準亦涵蓋第1層）。

端口速記：
HTTP 80｜HTTPS 443｜DNS 53（UDP/TCP）｜DHCP server 67 / client 68（UDP）
POP3 110（TCP）｜IMAP 143（TCP）｜NTP 123（UDP）｜SNMP 161（UDP；trap 162）
TFTP 69（UDP）｜RDP 3389（TCP/UDP）｜OpenVPN 常用1194（UDP，可配置）

【3｜Office：快捷鍵與參照】
PPT：F5從頭放映；Shift+F5當前頁；E清除放映筆跡；Ctrl+M新投影片；Ctrl+D複製物件。
PPT：選取窗格隱藏物件；自訂放映抽選精華投影片；改起始編號在設計/投影片大小/自訂；顯示編號在插入。
Word：Ctrl+P列印；Ctrl+Enter分頁；Ctrl+E置中；Ctrl+Y重做；合併列印在「郵件」。
Word：目前頁面＝游標所在頁；逐份列印＝1…5後再1…5；表格求上方數字＝SUM(ABOVE)。
防他人閱讀＝檔案/資訊/保護文件/以密碼加密；不是只限制編輯。
Excel：Ctrl+N新活頁簿；Ctrl+Enter讓整個選取範圍填同值；Alt+=自動加總；Ctrl+`顯示公式。
分頁預覽看分頁；整頁模式/頁面配置看頁首頁尾；只要結果→貼上值；橫直互換→轉置。
文字數字前導字元＝單引號 '；等差固定加、等比固定乘；AND全真才真，TRUE AND FALSE＝FALSE。
SUM(B4:B8)；工作表!格位；跨活頁簿 =[KAY.XLS]SHEET1!$A$1；$固定欄或列。
公式「隱藏」還要啟用工作表保護；篩選不會改写原儲存格。INDEX是查閱函數，不是邏輯函數。

【4｜HTML / CSS / 編碼】
<title>瀏覽器標題；<head>元資料；<body>頁面主體；<h1>最高標題；<br>換行。
<img alt="…">替代文字；<input type="radio">圓形單選；type="checkbox"方形複選。
CSS：.class、#id、*萬用；color文字色；font-size文字大小；text-decoration:none去底線；/*註解*/。
h1 div 選 h1 裡的 div；p{color:red} 選全部 p；target="_blank"通常開新分頁。
JS宣告用 let/const/var，=是賦值。GET資料在URL query；POST通常在body，POST本身不加密，保護敏感資料仍需HTTPS。
黑RGB(0,0,0)、白(255,255,255)；舊簡體GB2312、舊繁體Big5；現代通常UTF-8。

【5｜硬體／格式／數制】
MBR在磁盤第一磁區＝LBA 0；舊BIOS常用Active分區，UEFI用EFI系統分區。
Windows：NTFS；Apple：APFS/HFS+；Linux：ext；跨Win/Mac外接盤常選exFAT/FAT32。
HDD磁軌同心圓；Cache提升突發效能；SSD無机械部分，別套用HDD傳統碎片整理。
DDR4標準1.2V；DDR3常1.5V；DDR5常1.1V。DDR速度應分清MT/s與實際MHz。
eSATA e＝external；SATA＝Serial Advanced Technology Attachment。
PSU：OVP過壓、OCP過流、SCP短路、OPP過功率、OTP過溫、UVP欠壓。
100MB÷5Mbit/s＝100×8÷5＝160秒（忽略開銷）；1Byte＝8bits。
無損FLAC/APE；有損MP3；GIF可動畫；常見BMP未壓縮。DVD10＝雙面單層約9.4GB。
二進位每4位→十六進位，每3位→八進位；XOR相同0不同1。
10110111₂=B7₁₆；B5₁₆=181；139₁₀=213₈；467₁₀=723₈；482₁₀=111100010₂。
524₁₀=1000001100₂；213₁₀=D5₁₆；419₁₀=1A3₁₆；10010111₂=227₈；1101111₂=157₈。
Java最初Sun；VirtualBox最初innotek，現由Oracle維護；Deep Blue IBM；AlphaGo DeepMind；文心一言百度。
